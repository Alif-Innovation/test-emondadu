# About Emondadu

**Emondadu** is a modern, production-ready React.js dashboard for managing Village Fund (Dana RT) allocation and planning in Indonesia.

---

## 🌐 Live Application

**Visit the live dashboard**: https://alif-innovation.github.io/test-emondadu/

The application is deployed on GitHub Pages and automatically updates with each push to the main branch.

---

## 🎯 Project Overview

### What is Emondadu?

Emondadu is a digital platform designed to help Village Fund (Dana RT) administrators and village leaders manage financial allocations, plan infrastructure development, and track community demographics.

### Target Users

- **RT Chairs (Ketua RT)** - Village neighborhood leaders
- **Village Officials** - Planning and budgeting staff
- **Community Members** - Stakeholders in development planning

### Key Features

- 📊 **Budget Management** - Track allocations and spending
- 👥 **Demographics** - View population and household data
- 📈 **Statistics** - DESIL analysis for targeting programs
- 🏗️ **Infrastructure** - Monitor development projects
- 📋 **Documentation** - Access regulatory documents

## 🔧 Installation & Setup

### Prerequisites
- Node.js 18 or higher
- npm 9 or higher
- Git

### Quick Start

```bash
git clone https://github.com/Alif-Innovation/test-emondadu.git
cd test-emondadu
npm install
npm run dev
```

Visit `http://localhost:5173` to see the dashboard.
